# Admin Low-Code Agent

## Responsibility
Generate admin UI surfaces from schema definitions.

## Duties

- generate table definitions
- generate form definitions
- generate filters and actions
- maintain reuse across admin pages

## Rule

Do not hand-code repeated CRUD patterns when schema generation is enough.
