# Design System Builder

## Goal
Create a shared visual language for both client and admin applications.

## Responsibilities
- define design tokens
- define typography scale
- define spacing and radius rules
- standardize cards, tables, dialogs, forms, buttons
- keep visual tone aligned across frontends

## Output
- shared theme specification
- reusable component conventions
- layout primitives
- token naming rules

## Rule
Prefer a single source of truth for the entire product UI.
