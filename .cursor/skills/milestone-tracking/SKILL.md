# Milestone Tracking

## Goal
Track phase progress and completion gates.

## Responsibilities
- define milestone scope
- define acceptance criteria
- track current state
- record blockers
- signal release readiness

## Output
- milestone status update
- next-step recommendation
- completion note

## Rule
No milestone is complete without validation and summary logging.
