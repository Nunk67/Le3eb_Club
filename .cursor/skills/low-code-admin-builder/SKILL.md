# Low-Code Admin Builder

## Goal
Generate admin pages from schemas and configuration.

## Responsibilities
- convert entity definitions into admin pages
- generate table schemas
- generate form schemas
- generate action schemas
- generate filters and pagination controls

## Output
- entity configuration
- admin page blueprint
- reusable CRUD patterns

## Rule
One schema should be able to drive multiple admin UI surfaces.
