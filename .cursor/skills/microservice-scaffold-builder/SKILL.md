# Microservice Scaffold Builder

## Goal
Create service boundaries and contracts for the backend platform.

## Responsibilities
- identify domain boundaries
- define service responsibilities
- define API contracts
- define gateway routing expectations
- define DTO boundaries

## Output
- service map
- route map
- contract notes
- migration notes

## Rule
Do not collapse distinct business domains into one monolithic service.
