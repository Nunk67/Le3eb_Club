# Seed Data Generator

## Goal
Create useful bootstrap data for development and validation.

## Responsibilities
- generate representative users
- generate companion profiles
- generate orders
- generate reviews
- generate wallet and recharge data
- create default admin credentials

## Rule
Seed only when the relevant store is empty.
