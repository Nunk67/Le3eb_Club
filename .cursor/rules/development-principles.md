# Development Principles (Rule)

Executable distillation of global principles from `.cursor/harness/milestones.md`.

- Single source of truth
- Minimal change
- Evidence-based decisions
- Context convergence
- State-driven architecture
- Controlled complexity (shallow surfaces)
- Explicit over implicit
- No duplicated logic
- Data-driven over branching
- Fail fast
- Idempotent operations
- Observable system
- Clear boundary isolation
- Refactor on trigger
