# Milestone Plan

## Goal
Track the project in stable, reviewable phases.

## Milestone model

Each milestone must define:

- objective
- scope
- deliverables
- acceptance criteria
- validation requirements
- version tag

## Suggested milestones

### M0 — Harness Foundation
- rules
- skills
- subagents
- commands
- validators
- context-control

### M1 — Design System Unification
- shared theme
- shared UI tokens
- common components

### M2 — Backend Platform Split
- API gateway
- service boundaries
- service contracts

### M3 — Low-Code Admin System
- schema-driven tables
- schema-driven forms
- admin dashboards

### M4 — Client Security Hardening
- auth flow
- transaction safety
- state isolation
- sensitive data handling

### M5 — Frontend Pruning
- remove demo-only logic
- preserve styles/components/types
- keep interaction logic only

### M6 — Feedback + Context + Versioning Closed Loop
- validators
- context compression
- version snapshots
- milestone completion gates
