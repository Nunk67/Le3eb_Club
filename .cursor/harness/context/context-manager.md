# Context Manager

## Purpose
Keep active context short and persistent project memory stable.

## When to write
- after each major command
- after each milestone
- before phase switching
- when context grows too large

## What to include
- timestamp
- completed progress
- project summary
- thinking / design notes
- suggestions
- supplementary notes

## Storage rule
Append only to the repository root `context-control.md`. Never overwrite earlier entries.
