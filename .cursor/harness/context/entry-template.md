# Context log entry template（写入根目录 `context-control.md`）

根目录 `context-control.md` 为项目运行中记忆日志，**只追加、不覆盖**历史条目。新条目可按下述结构组织（与 bundle 中 `context-control/context-control.md` 一致）。

## Append-only format

Each entry must include:

- timestamp
- completed progress
- current project understanding
- design thoughts
- suggestions
- supplements / notes

- ...
