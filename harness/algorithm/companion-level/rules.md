# 陪玩等级规则总览

## 1. 等级结构

积分用 `x` 表示，按周结算后的总积分映射等级：

- 等级 1：`x < 200`
- 等级 2：`200 <= x < 400`
- 等级 3：`400 <= x < 800`
- 等级 4：`800 <= x < 1500`
- 等级 5：`1500 <= x < 2500`
- 等级 6：`x >= 2500`

## 2. 周结算通用规则

- 自然周按 `UTC+3` 切分。
- 结算日前一日 `23:00 (UTC+3)` 开始维护。
- 结算日 `04:00 (UTC+3)` 前完成发分。
- 发分完成前，用户端展示上周已结算分。
- 结算日发分前产生的变动，暂存到下一周期。
- 加减分按事件时间先后入账。

### 2.1 结算日配置

结算日不硬编码，使用配置项 `settlement_weekday`：

- 取值：`1-7`
- 含义：按 `UTC+3` 的周一到周日

## 3. 分数任务规则

### 3.1 活跃项（周封顶 150 分）

- 登录：每天 `+3`，周上限 `15`
- 发帖：每天 `+5`，周上限 `15`
- 打招呼：新用户且有回复，每人 `+5`，周上限 `50`
- 5 分钟回复率：仅 Online 统计
  - 公式：`已回复消息数 / 收到消息总数`
  - 档位：`>=90% => 35`，`75%-90% => 20`，`60%-75% => 5`，`<60% => 0`
- 5 分钟接单率：仅 Online 统计
  - 公式：`5分钟内接单成功数 / 可接订单邀请总数`
  - 分母：未超时、未撤单、非系统屏蔽
  - 分子：5 分钟内接受且进入有效订单状态（`PENDING/ONGOING/COMPLETED`）
  - 分母为 0：按 0 分并标记无样本周
  - 档位同回复率

### 3.2 服务项

- 服务新用户：每人 `+10`，周上限 `100`
- 复购用户：每人 `+5`，周上限 `100`
- 订单评分：
  - `x = 订单结算后星级总和`
  - `1星 = 1分`
  - 未评价默认 `5星`
  - 改分按当前有效评分，并按评分生效时间归属周（UTC+3）
  - 档位：`x>=150 => 50`，`100<=x<150 => 30`，`50<=x<100 => 10`，`20<=x<50 => 5`
- 礼物收入：每 `10` 钻石 `+2`
- 总收入：每 `20` 钻石 `+1`

## 4. 衰减与惩罚

### 4.1 周衰减

- 等级 1：`2%`
- 等级 2：`4%`
- 等级 3：`5%`
- 等级 4：`6%`
- 等级 5：`7%`
- 等级 6：`8%`

### 4.2 惩罚

- 前一周无订单收入：`-50`
- 前两周无订单收入：`-100`
- 前三周无订单收入：`-150`
- 前四周无订单收入：`-200`（封顶 `200`）

连续四周等级 1，取消陪玩资格，一个月后可重新申请。

### 4.3 保护规则

- 刚升级当周：不衰减，但惩罚照常。
- 积分 `<= 0`：不衰减，不惩罚。

## 5. 等级权益

### 5.1 定价权益

- 等级 1：`20-30`
- 等级 2：`30-40`
- 等级 3：`40-60`
- 等级 4：`50-80`
- 等级 5：`60-100`
- 等级 6：`80-150`
