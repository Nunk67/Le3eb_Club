# 政策成本测算验算基线（不含公会月奖励）

## 1. 验算公式

- `base_cost_rate = 40%`
- `weekly_bonus_rate ∈ {5%, 6%, 8%, 10%, 15%, 20%}`
- `total_cost_rate = base_cost_rate + weekly_bonus_rate`

## 2. 标准映射

| 周奖励 | 总成本率（应得） |
|---|---|
| 5% | 45% |
| 6% | 46% |
| 8% | 48% |
| 10% | 50% |
| 15% | 55% |
| 20% | 60% |

## 3. 约束说明

- 任何包含“公会月奖励/公会分成”的合并成本率，一律视为不在当前规则范围。
- 验算时仅允许使用基础成本率与陪玩周奖励两项。

## 4. 算法门禁验收项（POL）

- `POL-01` 基础成本率固定为 `40%`。
- `POL-02` 周奖励档位仅允许 `5/6/8/10/15/20` 六档。
- `POL-03` 总成本率必须严格等于 `40% + 周奖励`。
- `POL-04` 不得引入公会月奖励/分成字段参与计算。
- `POL-05` 结果集合必须严格为 `45/46/48/50/55/60`（无其他值）。

## 5. 验收结论规则

仅当 `POL-01` 到 `POL-05` 全部通过，才允许进入下一阶段。
