# 政策成本测算规则（不含公会月奖励）

## 1. 目标

本规则用于运营政策成本测算，专用于验证成本率区间是否符合当前定稿口径。

## 2. 适用范围

- 适用于基础成本与陪玩周奖励的成本测算。
- 明确排除：公会月奖励、公会月分成相关口径。

## 3. 基础口径

- 基础成本率：`40%`
- 陪玩周奖励档位：`5%`、`6%`、`8%`、`10%`、`15%`、`20%`
- 总成本率（本规则）：`基础成本率 + 陪玩周奖励`

## 4. 明确排除项

以下内容不参与当前算法、不参与开发与验算：

- 公会月奖励
- 公会月分成
- 所有“基础成本率 + 周奖励 + 公会奖励”三项叠加口径

## 5. 输出结果（标准档位）

按照当前规则，最终总成本率必须落在以下固定结果：

- `45%`
- `46%`
- `48%`
- `50%`
- `55%`
- `60%`
